# BharatCode 共享 harness 与工作流工作区

[English](2026-10-08-bharatcode-workspaces.md) | 中文

此实现遵循用户批准的发布规范。从已核实的 GitHub master 开始，在隔离 worktree 中工作；保留候选分支、现有 profile、凭据及历史会话世代。保留 Electron、React、TypeScript、Cordis 及上游技术包标识符。Linux、Windows 和 web 使用同一修订。财务、群体 agent、marketplace、同步和协作编辑不属于此发布范围。

## 任务 1 — BharatCode 品牌

在侧栏、窄栏、欢迎页、引导、图标、托盘、favicon 和包中使用现有橙色括号与菱形 SVG。可见产品名为 BharatCode。建立暖中性色浅色/深色界面、橙色强调色及共享字体、间距、控件、对话框和焦点状态。保留现有存储位置和提供方凭据。从交付组合中移除排除的产品条目，同时保留内部 loader 机制。交付可用的品牌预览、针对性检查及现有/新建 profile 验证。

## 任务 2 — 共享项目知识与交接

工作区身份即项目身份。添加类型化 Cordis 知识、工作流分配、交接和捕获上下文服务，并生成 Remote 接口。笔记和手稿仍为 Markdown 文件；宿主私有存储保存索引、批注、修订、链接和交接。注册和检索选定产物及对话摘录，而非无差别索引项目文件。有界不可变捕获记录目标、所选证据、参考资料、约束、问题、省略通知及原始会话/修订。区分假设、发现和已接受决定。每次接纳模型可见内容都必须记录日志。支持新建/现有目标、持久化的下一轮队列、明确选择的 steering（中途引导）、幂等重试、陈旧指示、明确刷新及明确选择的跨项目转移。在输入框旁显示 Using context。验证重启/回放、缺失/超大/变化的资料、冲突决定，以及 Research → Coding → 结果反向链接和 Research → Writing。

## 任务 3 — 共享 shell 与工作布局

扩展现有停靠机制，支持聊天、编辑器/阅读器、资源管理器/大纲及辅助窗格。提供展开侧栏、折叠窄栏、隐藏 Focus；Document focus、Chat focus、Balanced、Focus 预设；交换两侧、拖动预览、调整大小、重置及键盘替代操作。持久化项目/工作流默认值，以及各会话的标签页、光标/阅读位置、草稿、宽度、窗格顺序和侧栏。按版本迁移旧停靠布局；窄屏显示不得覆盖桌面布局。导航不能更改正在运行的任务、权限或 cwd。

Coding：延迟加载的 Monaco 可编辑文件、标签页、搜索/替换、诊断、符号、通过宿主 LSP 支持 TS/JS、检查版本的保存、恢复/冲突比较、终端/监视复用、选区上下文及 agent（智能体）变更审查。

Research：资料库、PDF/文档阅读器、证据笔记及 Markdown 综合分析；带扫描 PDF 指示的文本提取；修订/页码/范围/引文引用及引用导航、段落提问/捕获和交接。

Writing：大纲、舒适的 Lexical 手稿编辑及 Markdown 导入/导出，对不支持的结构保留完整源码模式，故事设定集、明确插入、选定修订、评论、连贯性、章节顺序和 Focus。打开文件绝不重写文件。验证草稿恢复、并发 agent 编辑、Markdown 往返转换、Unicode 和 Windows 路径、切换/重启及键盘操作。

## 任务 4 — 保留的英文集成

保留 BharatCode Visuals（dsh-visuals）、Engram、Context、Zero（dsh-zero）、Provider Hub/subscriptions、SearXNG、Skills Manager、Tool Call Guard、Cost Meter。在干净的规范源代码上工作，重建组合包、检查打包内容并验证真实 Cordis 生命周期/组合/重启。通过经过审查的有界提供方批次和术语表翻译 UI/设置/帮助/错误/工具文本/提示词/文档。保留标识符/schema/插值/路由及用户或获许可内容。将 Engram 绑定到稳定 Workspace ID；在副本上验证嵌入迁移，保留原始内容并测试导入/恢复。Visuals 保留原生正文/工具/推理/附件，并使用包/会话状态而非 marketplace 状态。仅使用共享设置。实际修复格式错误的调用必须使用受支持的提供方拦截 seam；仅检测不等于修复。可选集成不可用时，核心项目/交接功能仍能运行。

## 任务 5 — 原创图形、动效与打磨

OpenGhost 的许可证不涵盖动画及视觉设计：创建原创 BharatCode 实现。共享时长：反馈 120 ms、对话框/工作区 200 ms、侧栏 240 ms、初始图形 300 ms。保持 shell 稳定、取消失效导航过渡、指针调整大小立即响应、对停靠就位使用动画。流式输出不得逐 token 重启动画或覆盖历史阅读。图形只首次显示时出现动效，不在调整大小/历史/标签页恢复时重播。延迟加载编辑器/渲染器，并暂停隐藏渲染而不丢失草稿/任务。提供无障碍对话框/焦点/加载/错误、减少动效及浅色/深色图形；验证流式输出、格式错误图表净化、可编辑源内容和 SVG 导出。

## 任务 6 — 集成验证与交付

各阶段运行针对性单元测试和真实 Cordis 组合检查、相关无需密钥的会话/web 快照，以及生成配置/类型/SDK 变更确认和文档检查。运行仓库构建/类型/lint/配置/快照/兼容性门禁；验证同一修订的 Linux/Windows/web 打包产物及现有 profile 升级。CI 使用确定性 fixture（测试前置数据），真实提供方推理单独报告。最后进行新的完整分支审查，修复实质问题，并交付阶段提交/预览及准确证据和剩余限制。不要静默合并候选 PR（Pull Request）。
