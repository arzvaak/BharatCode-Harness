# 3D Creation Implementation Plan

> **For agentic workers:** Primary implements inline; mandated Luna Max agent handles release preparation, packaging, qualification, publishing and installation.

**Goal:** DeepSeek can create, preview, render and export editable Blender, Three.js and Babylon.js projects.

**Architecture:** Preserve DeepBlend upstream and adapt proven host mismatches. Share browser project and rendering infrastructure in an optional native 3D toolkit with two engine tool families.

**Tech Stack:** Node ESM, esbuild, Three.js, React Three Fiber, Drei, Rapier, Babylon.js, Playwright Chromium, Blender/DeepBlend.

**Spec:** `docs/superpowers/specs/2026-10-19-3d-creation-design.md`

## Global Constraints

- Workspace-owned data and independent generated-code browser origin.
- Never execute model source in Node; no project-triggered dependency installation.
- Images must contain rendered geometry; exports must parse and retain editable source.
- Native qualification is platform-specific and artifact-bound.
- All release tasks delegated to gpt-6-luna/max.

## Review Focus

- Project traversal/symlink escape must not expose host files.
- Concurrent edits and stale previews must retain deterministic revision identity.
- Failed initialization must not return successful blank renders.
- Exported viewers must load without development servers or CDNs.
- Cancellation and unload must close rendering browsers and the preview server.
