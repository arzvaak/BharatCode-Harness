# 上游兼容性实施计划

[English](2026-10-02-upstream-compatibility.md) | 中文

**目标：** 在保留独立品牌修改工作树的同时，通过经审核的候选 PR 集成上游，并提供 Linux、Windows 与 Web 证据。

**架构：** 已提交的接受上游记录与行为登记表驱动漂移报告。GitHub App 准备唯一的向前合并候选 PR。确定性的构建后配置档案测试与平台工作流共同形成必需汇总检查；发布候选保留不可变证据与产物。

**任务**

- [ ] 添加接受基线元数据、行为登记表、漂移与候选辅助程序，以及临时仓库回归测试。
- [ ] 添加脱敏桌面配置组合、构建后运行时激活、搜索与模型检查、自动续写行为测试及负向对照。
- [ ] 扩展 CI，包含完整单元测试、重放、预期输出、Web、Linux 桌面与 Windows 打包检查，以及不可变证据。添加明确的真实提供方与发布候选验证。
- [ ] 添加每日 GitHub App 候选自动化、迁移验证、操作说明，并强制经审核的受保护合并。
- [ ] 本地验证、发布供审核的 PR、检查托管结果，并记录尚未解决的外部设置，不宣称其已通过。

**约束：** 夹具不得包含密钥或个人配置档案；不得删除测试、自动重写快照、广泛排除、自动合并或修改品牌。原生 Windows 使用 pwsh。缺少凭据时明确失败。上游冲突会停止集成并报告受影响的行为。

**验证：** 负向对照拒绝无效配置目标、禁用的必需插件、错误提供方选择、续写故障与缺失运行时依赖。使用临时 Git 仓库测试候选准备，包括重复运行与冲突。运行针对性本地测试和构建；托管 CI 负责完整及平台套件。
