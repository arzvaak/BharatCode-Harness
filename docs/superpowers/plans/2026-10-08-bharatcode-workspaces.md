This implementation follows the user-approved release specification. Start from verified GitHub master in an isolated worktree; retain candidate branches, existing profiles, credentials, and historical session generations. Keep Electron, React, TypeScript, Cordis, and upstream technical package identifiers. Linux, Windows, and web share the revision. Finance, swarms, marketplaces, sync, and collaborative editing are outside this release.

Workspace identity is project identity. Add typed Cordis knowledge, workflow assignment, handoff, and captured-context services with generated remotes. Show Using context beside the composer. Verify restart/replay, missing/oversized/changed sources, conflicting decisions, and Research → Coding → result backlink plus Research → Writing.

## Task 3 — Shared shell and working layouts

Extend existing docking with chat, editor/reader, explorer/outline, and supporting panes. Expanded sidebar, collapsed rail, hidden Focus; Document focus, Chat focus, Balanced, Focus presets; swap sides, drag previews, resizing, reset, keyboard alternatives. Persist project/workflow defaults and per-session tabs, cursor/reading position, draft, widths, pane order and sidebar. Migrate legacy docks versionedly; narrow presentation must not overwrite desktop layout. Navigation cannot change running tasks, permissions, or cwd.

Coding: lazy Monaco editable files, tabs, search/replace, diagnostics, symbols, TS/JS through host LSP, version-checked saves, recovery/conflict comparison, terminal/watch reuse, selection context and agent changes review.

Research: source library, PDF/document reader, evidence notes and Markdown synthesis; text extraction with scanned-PDF indicator; revision/page/range/quote references and citation navigation, passage questions/capture and handoffs.

Writing: outline, Lexical manuscript comfort with Markdown import/export and intact source mode for unsupported structures, story bible, explicit insertion, selected revisions, comments, continuity, chapter order, Focus. Opening files never rewrites them. Verify draft recovery, concurrent agent edits, Markdown round trips, Unicode and Windows paths, switching/restart and keyboard operation.
