# 独立聊天文件夹

[English](guide.md) | 中文

## 变更

未指定 `workspaceId` 或 `cwd` 的新 `session.create` 请求在 `$DSH_HOME/chats` 下创建独立文件夹。通用新建会话创建独立聊天；显式工作区创建保留工作区归属。全新安装不登记默认工作区。已保存的会话保留现有工作目录和归属。

## 迁移

1. 需要特定工作目录的调用方必须提供 `cwd`，或提供已登记工作区的 `workspaceId`。
2. 独立聊天使用通用新建会话；项目聊天使用工作区选择器。
3. 确认新的独立聊天文件夹出现在 `$DSH_HOME/chats` 下，而不显示为已登记工作区。无需移动现有日志或文件夹。
