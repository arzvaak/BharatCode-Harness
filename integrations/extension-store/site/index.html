Linux preview. Windows and ARM64 builds are not available in this release. AppImage requires a desktop with FUSE support.

A few things to know.

Do I need to choose a provider right away?

No. Choose “Set up later” during onboarding and connect a provider from Settings whenever you’re ready. You’ll need a configured provider to send model requests.

Does every chat need a workspace?

No. General chats are independent and have their own files. Create a chat from a workspace when you want it assigned to that project.

How do updates work?

The app checks the public BharatCode GitHub releases. An update is downloaded only when you choose it. You confirm the restart before installation, and the app checks for running work first. RPM and DEB installations may request system authorization.

What if I’m on an older AppImage?

Older releases without the in-app updater need one manual installation of this release. Future supported releases can then be installed from within the app.

Where do I find extensions and skills?

Open Extensions or Skills from the sidebar. Review the tool’s requirements, then follow the installation and setup controls in the app.
