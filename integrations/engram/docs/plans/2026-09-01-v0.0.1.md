# dsh-engram v0.0.1 Implementation Plan

> **For agentic workers:** Execute the tasks in order, using checkbox (`- [ ]`) syntax to track steps.

**Goal:** Deliver dsh-engram v0.0.1 (phase 1 of the design doc): an installable BharatCode Harness memory plugin skeleton + SQLite dual-database storage + local Chinese embedding + 5 basic tools + session-start profile injection, all with tests.

**Architecture:** Single plugin package (billing mode): `apply` registers 5 `engram_` tools and hooks into the `agent/pre-step` waterfall to inject the user profile; the storage layer has the `EngramStore` interface + node:sqlite implementation (nodes table, edges table, FTS5, operation log, monotonically increasing SCHEMA_VERSION); the embedding layer has the `EngramEmbedder` interface + transformers.js implementation, with retrieval degrading to FTS-only when missing or failed.

**Tech Stack:** TypeScript (ESM, NodeNext), Cordis function plugin (`name`/`inject`/`Config`/`apply`), `defineTool` from `@deepseek-ai/dsh-tools`, `node:sqlite` (dynamic import), `@huggingface/transformers` (`Xenova/bge-small-zh-v1.5`, 512-dim), vitest, tsdown, pnpm.

**Source of API facts (verified):** Tool registration `toolsCtx.tools.register(defineTool({...}))` (template `packages/client/ui-usage-billing/src/index.ts`); dynamic context injection goes through `ctx.on('agent/pre-step', listener, { prepend: true })` + `createUserMessage({ source: { kind: 'plugin', plugin, form: 'snapshot', sections: [{ name, text }] } })` (template `packages/context/time-context/src/index.ts`); `node:sqlite` uses `const { DatabaseSync } = await import('node:sqlite')` (template `packages/session-query/session-query-sqlite/src/schema.ts`).

**Two cuts to the design skeleton (recorded in the commit message):** ① The `./invariant` entry and the independent file `src/presenter.ts` move to phase 2 — v0.0.1 tool presentation goes through `output.render` plain-text rendering and the generic client card; ② The source attribution chain in v0.0.1 only records `sourceSessionId` (`exec.agent?.id`); `round`/`seq` etc. will be completed when auto-ingest lands.

```ts
/**
 * dsh-engram vocabulary: memory entries, relationship edges, queries and errors.
 * @module @kenz1117/dsh-engram/types
 */

/** Branded memory id: ids crossing tool and storage boundaries are all this type, rejecting bare string. */
declare const memoryIdBrand: unique symbol
export type MemoryId = string & { readonly [memoryIdBrand]: true }

/** Cast an arbitrary string to a branded id (called by the storage layer before entering the database). */
export function asMemoryId(raw: string): MemoryId { return raw as MemoryId }

/** Memory scope: user is global shared; project splits databases by working directory. */
export type EngramScope = 'user' | 'project'

/** Memory kind: fact / preference / decision / episode / skill. */
export type EngramKind = 'fact' | 'preference' | 'decision' | 'episode' | 'skill'

/** Entry status: active participates in retrieval; archived (decay/superseded) does not participate in retrieval, can be restored; forgotten is soft-deleted, can be restored. */
export type EngramStatus = 'active' | 'archived' | 'forgotten'

/** Relationship edge type. supersedes semantics: from supersedes to. */
export type EngramEdgeType = 'supports' | 'contradicts' | 'refines' | 'related' | 'supersedes'

/** A memory. The source attribution chain in v0.0.1 records sourceSessionId; round/seq will be completed by phase 2 auto-ingest. */
export interface MemoryRecord {
  readonly id: MemoryId
  readonly scope: EngramScope
  readonly kind: EngramKind
  readonly content: string
  /** 0-1: importance, affects injection sorting and decay scheduling. */
  readonly importance: number
  /** 0-1: confidence, raised by hit reinforcement, reverted on distill failure. */
  readonly confidence: number
  readonly status: EngramStatus
  readonly createdAt: number
  readonly lastAccessedAt: number
  readonly accessCount: number
  readonly sourceSessionId: string | null
}

/** Memory relationship edge. */
export interface MemoryEdge {
  readonly from: MemoryId
  readonly to: MemoryId
  readonly type: EngramEdgeType
  readonly createdAt: number
}

/** Write request. */
export interface WriteInput {
  readonly scope: EngramScope
  readonly kind: EngramKind
  readonly content: string
  readonly importance?: number
  readonly confidence?: number
  readonly sourceSessionId?: string | null
}

/** Search request. */
export interface SearchQuery {
  readonly text: string
  readonly scopes: readonly EngramScope[]
  readonly limit?: number
}

/** A search hit. */
export interface SearchHit {
  readonly record: MemoryRecord
  /** Fused score (RRF), higher means more relevant. */
  readonly score: number
  /** The contributing path that hit this entry: fts keyword / vec semantic / both. */
  readonly via: 'fts' | 'vec' | 'both'
  /** When introduced via one-hop relationship edge expansion, the source entry id. */
  readonly viaEdge?: { readonly from: MemoryId; readonly type: EngramEdgeType }
}

/** Search result: degraded=true indicates embedding missing/failed, only the keyword path participates in sorting. */
export interface SearchResult {
  readonly hits: readonly SearchHit[]
  readonly degraded: boolean
}

/** Timeline query. since/until are epoch milliseconds; topic is substring match. */
export interface TimelineQuery {
  readonly since?: number
  readonly until?: number
  readonly topic?: string
  readonly scopes: readonly EngramScope[]
  readonly limit?: number
}

/** Update request: the old entry is turned into archived and a supersedes edge is created (from=new, to=old). */
export interface UpdateInput {
  readonly id: MemoryId
  readonly scope: EngramScope
  readonly kind: EngramKind
  readonly content: string
  readonly importance?: number
}

/** dsh-engram unified error: all diagnosable failures during load/use throw this type. */
export class EngramError extends Error {
  /** Machine-readable reason code, e.g. EMBEDDER_UNAVAILABLE / SCHEMA_INCOMPATIBLE. */
  readonly code: string
  constructor(code: string, message: string, options?: { cause?: unknown }) {
    super(message, options)
    this.name = 'EngramError'
    this.code = code
  }
}
```

```ts
/**
 * Plugin Config: all deployment-mutable items are centralized here, no embedding defaults in the implementation.
 * @module @kenz1117/dsh-engram/config
 */

import { homedir } from 'node:os'
import { join } from 'node:path'
import z from '@deepseek-ai/schemastery'

/** Plugin configuration. */
export interface EngramConfig {
  /** Root directory for the two SQLite databases and the embedding model cache; default `~/.dsh/engram`. */
  dbDir?: string
  /** Whether to inject a user-level profile summary at session start; default true. */
  injectProfile?: boolean
  /** Maximum number of entries for profile injection; default 8. */
  profileTopN?: number
  /** Embedding model cache directory; default `<dbDir>/models`. */
  modelCacheDir?: string
}

/** Resolved complete config (explicit defaults centralized in this one step, implementation no longer does `?? default`). */
export interface ResolvedEngramConfig {
  readonly dbDir: string
  readonly injectProfile: boolean
  readonly profileTopN: number
  readonly modelCacheDir: string
}

/** Schemastery validation surface (validated when cordis.yml reads). */
export const Config: z<EngramConfig> = z.object({
  dbDir: z.string(),
  injectProfile: z.boolean(),
  profileTopN: z.number().int().min(1).max(64),
  modelCacheDir: z.string(),
})

/** Explicit resolve step: defaults land only in this one place, illegal values fail loudly. */
export function resolveConfig(config: EngramConfig = {}): ResolvedEngramConfig {
  if (config !== null && typeof config === 'object') {
    for (const key of Object.keys(config)) {
      if (!(key in Config['meta'] ?? {}) && !['dbDir', 'injectProfile', 'profileTopN', 'modelCacheDir'].includes(key)) {
        throw new Error(`dsh-engram: unknown config key "${key}"`)
      }
    }
  }
  const dbDir = config.dbDir ?? join(homedir(), '.dsh', 'engram')
  const injectProfile = config.injectProfile ?? true
  const profileTopN = config.profileTopN ?? 8
  if (config.profileTopN !== undefined && (!Number.isInteger(config.profileTopN) || config.profileTopN < 1 || config.profileTopN > 64)) {
    throw new Error('dsh-engram: profileTopN must be an integer in [1, 64]')
  }
  return { dbDir, injectProfile, profileTopN, modelCacheDir: config.modelCacheDir ?? join(dbDir, 'models') }
}
```

```ts
 * The implementation must satisfy: node/edge/operation log persistence; the caller holds two instances for scope database splitting.
 * @module @kenz1117/dsh-engram/store/interface

import type { MemoryId, MemoryRecord, SearchQuery, SearchResult, TimelineQuery, UpdateInput, WriteInput } from '../types.ts'

/** Write returns the new entry. */
export interface EngramStore {
  /** Append one active memory, content non-empty. */
  write(input: WriteInput): Promise<MemoryRecord>
  /** Get an entry by id; return undefined if not found. */
  get(id: MemoryId): Promise<MemoryRecord | undefined>
  /** Hybrid retrieval (vector + FTS5 + one-hop expansion). */
  search(query: SearchQuery, embeddings: Float32Array | undefined): Promise<SearchResult>
  /** Timeline query, in descending order of createdAt. */
  timeline(query: TimelineQuery): Promise<MemoryRecord[]>
  /** Correction: the old entry is turned into archived, a supersedes edge is created, return the new entry. */
  update(input: UpdateInput, embeddings: Float32Array | undefined): Promise<MemoryRecord>
  /** Soft delete (restorable). */
  forget(id: MemoryId): Promise<MemoryRecord>
  /** Restore from archived/forgotten to active. */
  restore(id: MemoryId): Promise<MemoryRecord>
  /** Profile injection: active entries in descending order of importance, confidence, take the top n. */
  topActive(scope: 'user', n: number): Promise<MemoryRecord[]>
  /** Physically clear all data of the specified scope (used after export). */
  purge(): Promise<void>
  /** Close the database handle. */
  close(): Promise<void>
}
```

```ts
/**
 * EngramStore's node:sqlite implementation: nodes table + edges table + trigram FTS5 + operation log,
 * monotonically increasing SCHEMA_VERSION, validated on open, incompatible refuses to load (no compatibility shim written).
 * @module @kenz1117/dsh-engram/store/sqlite
 */

import { mkdir, readFile } from 'node:fs/promises'
import { dirname } from 'node:path'
import { randomUUID } from 'node:crypto'
import type { DatabaseSync } from 'node:sqlite'
import { EngramError, asMemoryId } from '../types.ts'
import type { MemoryId, MemoryRecord, MemoryEdge, SearchHit, SearchResult, TimelineQuery, UpdateInput, WriteInput, EngramScope } from '../types.ts'
import type { EngramStore } from './interface.ts'

/** Current schema version; any structural change must +1 and refuse old databases (pre-release has no compatibility promise). */
const SCHEMA_VERSION = 1
/** The RRF constant for fusing the FTS path and the vector path. */
const RRF_K = 60
/** Upper bound of candidates for the vector path scan: all active entries with a vector participate in the cosine computation. */

interface NodeRow {
  id: string; scope: string; kind: string; content: string
  importance: number; confidence: number; status: string
  created_at: number; last_accessed_at: number; access_count: number
  source_session_id: string | null; embedding: Uint8Array | null
}

function rowToRecord(row: NodeRow): MemoryRecord {
  return {
    id: asMemoryId(row.id), scope: row.scope as EngramScope, kind: row.kind as MemoryRecord['kind'],
    content: row.content, importance: row.importance, confidence: row.confidence, status: row.status as MemoryRecord['status'],
    createdAt: row.created_at, lastAccessedAt: row.last_accessed_at, accessCount: row.access_count,
    sourceSessionId: row.source_session_id,
  }
}

function vecToBlob(vector: Float32Array): Buffer { return Buffer.from(vector.buffer, vector.byteOffset, vector.byteLength) }
function blobToVec(blob: Uint8Array): Float32Array { return new Float32Array(blob.buffer.slice(blob.byteOffset, blob.byteOffset + blob.byteLength)) }

/** Cosine similarity (equivalent to dot product when the embeddings are already normalized; still uses the full formula to defend against unnormalized vectors). */
function cosine(a: Float32Array, b: Float32Array): number {
  let dot = 0; let na = 0; let nb = 0
  const len = Math.min(a.length, b.length)
  for (let i = 0; i < len; i++) { dot += a[i]! * b[i]!; na += a[i]! * a[i]!; nb += b[i]! * b[i]! }
  if (na === 0 || nb === 0) return 0
  return dot / (Math.sqrt(na) * Math.sqrt(nb))
}

/**
 * Open (create if necessary) one scope database.
 * @param path - SQLite file path; the directory is created automatically if it does not exist (0o700).
 * @returns The ready EngramStore.
 * @throws EngramError(code=SCHEMA_INCOMPATIBLE) when the database version is higher than the current implementation.
 */
export async function openEngramStore(path: string): Promise<EngramStore> {
  await mkdir(dirname(path), { recursive: true, mode: 0o700 })
  const { DatabaseSync } = await import('node:sqlite')
  const db = new DatabaseSync(path)
  db.exec(`
    CREATE TABLE IF NOT EXISTS meta (key TEXT PRIMARY KEY, value TEXT NOT NULL);
    CREATE TABLE IF NOT EXISTS nodes (
      id TEXT PRIMARY KEY, scope TEXT NOT NULL, kind TEXT NOT NULL, content TEXT NOT NULL,
      importance REAL NOT NULL, confidence REAL NOT NULL, status TEXT NOT NULL,
      created_at INTEGER NOT NULL, last_accessed_at INTEGER NOT NULL, access_count INTEGER NOT NULL,
      source_session_id TEXT, embedding BLOB);
    CREATE TABLE IF NOT EXISTS edges (
      from_id TEXT NOT NULL, to_id TEXT NOT NULL, type TEXT NOT NULL, created_at INTEGER NOT NULL,
      PRIMARY KEY (from_id, to_id, type));
    CREATE TABLE IF NOT EXISTS op_log (
      seq INTEGER PRIMARY KEY AUTOINCREMENT, at INTEGER NOT NULL, op TEXT NOT NULL, target_id TEXT NOT NULL, detail TEXT);
    CREATE VIRTUAL TABLE IF NOT EXISTS nodes_fts USING fts5(node_id UNINDEXED, content, tokenize='trigram');
    CREATE INDEX IF NOT EXISTS nodes_status ON nodes (scope, status);
  `)
  const versionRow = db.prepare("SELECT value FROM meta WHERE key = 'schema_version'").get() as { value: string } | undefined
  if (versionRow === undefined) {
    db.prepare("INSERT INTO meta (key, value) VALUES ('schema_version', ?)").run(String(SCHEMA_VERSION))
  } else if (Number(versionRow.value) > SCHEMA_VERSION) {
    db.close()
    throw new EngramError('SCHEMA_INCOMPATIBLE', `engram database schema version ${versionRow.value} is higher than the plugin-supported ${SCHEMA_VERSION}, please upgrade the plugin`)
  }

  const now = (): number => Date.now()
  const log = db.prepare('INSERT INTO op_log (at, op, target_id, detail) VALUES (?, ?, ?, ?)')
  const insertNode = db.prepare(`INSERT INTO nodes
    (id, scope, kind, content, importance, confidence, status, created_at, last_accessed_at, access_count, source_session_id, embedding)
    VALUES (?, ?, ?, ?, ?, ?, 'active', ?, ?, 0, ?, ?)`)
  const insertFts = db.prepare('INSERT INTO nodes_fts (node_id, content) VALUES (?, ?)')
  const deleteFts = db.prepare('DELETE FROM nodes_fts WHERE node_id = ?')

  const recordOps = {
    get: db.prepare('SELECT * FROM nodes WHERE id = ?'),
    activeRows: db.prepare("SELECT * FROM nodes WHERE scope = ? AND status = 'active' AND embedding IS NOT NULL"),
    byIdIn: db.prepare('SELECT * FROM nodes WHERE id = ?'),
    ftsSearch: db.prepare(`SELECT n.*, bm25(nodes_fts) AS rank FROM nodes_fts f JOIN nodes n ON n.id = f.node_id
      WHERE nodes_fts MATCH ? AND n.status = 'active' AND n.scope = ? ORDER BY rank LIMIT 64`),
    setStatus: db.prepare('UPDATE nodes SET status = ?, last_accessed_at = ? WHERE id = ?'),
    touch: db.prepare('UPDATE nodes SET access_count = access_count + 1, last_accessed_at = ? WHERE id = ?'),
    topActive: db.prepare("SELECT * FROM nodes WHERE scope = 'user' AND status = 'active' ORDER BY importance DESC, confidence DESC LIMIT ?"),
    timeline: db.prepare(`SELECT * FROM nodes WHERE scope = ? AND status = 'active'
      AND (? IS NULL OR created_at >= ?) AND (? IS NULL OR created_at <= ?)
      AND (? IS NULL OR content LIKE '%' || ? || '%') ORDER BY created_at DESC LIMIT ?`),
    purgeAll: db.prepare('DELETE FROM nodes'),
    purgeEdges: db.prepare('DELETE FROM edges'),
    purgeFts: db.prepare("DELETE FROM nodes_fts"),
    purgeLog: db.prepare('DELETE FROM op_log'),
    upsertEdge: db.prepare('INSERT OR IGNORE INTO edges (from_id, to_id, type, created_at) VALUES (?, ?, ?, ?)'),
    neighbors: db.prepare(`SELECT * FROM edges WHERE from_id IN (SELECT value FROM json_each(?))
      AND type IN ('supports','refines','related')`),
  }

  const getRow = (id: string): NodeRow | undefined => recordOps.get.get(id) as NodeRow | undefined

  return {
    async write(input: WriteInput) {
      const content = input.content.trim()
      if (content === '') throw new EngramError('EMPTY_CONTENT', 'content cannot be empty')
      const id = asMemoryId(randomUUID())
      const at = now()
      db.transaction(() => {
        insertNode.run(id, input.scope, input.kind, content, input.importance ?? 0.5, input.confidence ?? 0.5, at, at, input.sourceSessionId ?? null, null)
        insertFts.run(id, content)
        log.run(at, 'write', id, JSON.stringify({ kind: input.kind, scope: input.scope }))
      })()
      return rowToRecord(getRow(id)!)
    },

    async get(id: MemoryId) {
      const row = getRow(id)
      return row === undefined ? undefined : rowToRecord(row)
    },

    async search(query, embeddings) {
      const limit = query.limit ?? 8
      const scores = new Map<string, { score: number; via: SearchHit['via'] }>()
      // Path 1: FTS5 trigram keyword.
      const ftsRows = db.prepare(`SELECT n.*, bm25(nodes_fts) AS rank FROM nodes_fts f JOIN nodes n ON n.id = f.node_id
        WHERE nodes_fts MATCH ? AND n.status = 'active' AND n.scope IN (${query.scopes.map(() => '?').join(',') || "''"})
        ORDER BY rank LIMIT 64`).all(query.text.replace(/["'()*]/g, ' '), ...query.scopes) as (NodeRow & { rank: number })[]
      ftsRows.forEach((row, index) => {
        scores.set(row.id, { score: 1 / (RRF_K + index + 1), via: 'fts' })
      })
      // Path 2: vector cosine (all active entries with a vector).
      let degraded = true
      if (embeddings !== undefined) {
        degraded = false
        const vecRows = db.prepare(`SELECT * FROM nodes WHERE status = 'active'
          AND embedding IS NOT NULL AND scope IN (${query.scopes.map(() => '?').join(',') || "''"})`).all(...query.scopes) as NodeRow[]
        const vecRanked = vecRows
          .map(row => ({ row, sim: cosine(embeddings, blobToVec(row.embedding!)) }))
          .filter(entry => entry.sim > 0.2)
          .sort((a, b) => b.sim - a.sim)
          .slice(0, 64)
        vecRanked.forEach((entry, index) => {
          const existing = scores.get(entry.row.id)
          const add = 1 / (RRF_K + index + 1)
          if (existing === undefined) scores.set(entry.row.id, { score: add, via: 'vec' })
          else scores.set(entry.row.id, { score: existing.score + add, via: 'both' })
        })
      }
      // One-hop relationship expansion: supports/refines/related neighbors, if active and not yet in the results, are introduced at low weight.
      const topIds = [...scores.entries()].sort((a, b) => b[1].score - a[1].score).slice(0, limit).map(([id]) => id)
      if (topIds.length > 0) {
        const edges = recordOps.neighbors.all(JSON.stringify(topIds)) as MemoryEdge[]
        for (const edge of edges.slice(0, 32)) {
          if (scores.has(edge.to) || topIds.includes(edge.to)) continue
          const row = getRow(edge.to)
          if (row === undefined || row.status !== 'active' || !query.scopes.includes(row.scope as EngramScope)) continue
          scores.set(edge.to, { score: scores.get(edge.from)!.score * 0.5, via: 'fts' })
          void 0
        }
      }
      // Sort truncate + hit reinforcement + viaEdge backfill.
      const finalRows = [...scores.entries()].sort((a, b) => b[1].score - a[1].score).slice(0, limit)
      const hits: SearchHit[] = []
      for (const [id, info] of finalRows) {
        const row = getRow(id)!
        hits.push({ record: rowToRecord(row), score: info.score, via: info.via })
        recordOps.touch.run(now(), id)
      }
      return { hits, degraded }
    },

    async timeline(query: TimelineQuery) {
      const limit = query.limit ?? 20
      const rows = db.prepare(`SELECT * FROM nodes WHERE status = 'active' AND scope IN (${query.scopes.map(() => '?').join(',') || "''"})
        AND (? IS NULL OR created_at >= ?) AND (? IS NULL OR created_at <= ?)
        AND (? IS NULL OR content LIKE '%' || ? || '%') ORDER BY created_at DESC LIMIT ?`)
        .all(...query.scopes, query.since ?? null, query.since ?? null, query.until ?? null, query.until ?? null, query.topic ?? null, query.topic ?? null, limit) as NodeRow[]
      return rows.map(rowToRecord)
    },

    async update(input: UpdateInput, embeddings) {
      const old = getRow(input.id)
      if (old === undefined) throw new EngramError('NOT_FOUND', `entry ${input.id} does not exist`)
      const content = input.content.trim()
      if (content === '') throw new EngramError('EMPTY_CONTENT', 'content cannot be empty')
      const id = asMemoryId(randomUUID())
      const at = now()
      db.transaction(() => {
        recordOps.setStatus.run('archived', at, input.id)
        insertNode.run(id, input.scope, input.kind, content, input.importance ?? old.importance, old.confidence, at, at, old.source_session_id, embeddings === undefined ? null : vecToBlob(embeddings))
        insertFts.run(id, content)
        recordOps.upsertEdge.run(id, input.id, 'supersedes', at)
        log.run(at, 'update', id, JSON.stringify({ supersedes: input.id }))
      })()
      return rowToRecord(getRow(id)!)
    },

    async forget(id: MemoryId) {
      const row = getRow(id)
      if (row === undefined) throw new EngramError('NOT_FOUND', `entry ${id} does not exist`)
      recordOps.setStatus.run('forgotten', now(), id)
      log.run(now(), 'forget', id, null)
      return rowToRecord(getRow(id)!)
    },

    async restore(id: MemoryId) {
      const row = getRow(id)
      if (row === undefined) throw new EngramError('NOT_FOUND', `entry ${id} does not exist`)
      recordOps.setStatus.run('active', now(), id)
      log.run(now(), 'restore', id, null)
      return rowToRecord(getRow(id)!)
    },

    async topActive(_scope: 'user', n: number) {
      const rows = recordOps.topActive.all(n) as NodeRow[]
      return rows.map(rowToRecord)
    },

    async purge() {
      db.transaction(() => {
        recordOps.purgeAll.run(); recordOps.purgeEdges.run(); recordOps.purgeFts.run(); recordOps.purgeLog.run()
      })()
      log.run(now(), 'purge', 'ALL', null)
    },

    async close() { db.close() },
  }
}

/** Embedding vector disk persistence helper: shared by the update path and the phase 2 ingest. */
export { vecToBlob, blobToVec }
```

```ts
/**
 * transformers.js local embedding implementation: Xenova/bge-small-zh-v1.5, quantized weights, offline inference.
 * The model requires a network connection on first use to download to cacheDir; afterwards it is fully offline.
 * @module @kenz1117/dsh-engram/embedder/local
 */

import { mkdir } from 'node:fs/promises'
import type { EngramEmbedder } from './interface.ts'
import { EngramError } from '../types.ts'

/** Singleton pipeline: repeated calls to createLocalEmbedder within a process share the same model instance. */
let cached: { dir: string; embedder: EngramEmbedder } | undefined

/** Release the shared pipeline (for test isolation; production does not need to call). */
export async function resetEmbedderCache(): Promise<void> { cached = undefined }

/**
 * Create a local embedder.
 * @param cacheDir - Model cache directory; created automatically if it does not exist.
 * @returns The ready EngramEmbedder.
 * @throws EngramError(code=EMBEDDER_DOWNLOAD_FAILED) model download/load failure.
 */
export async function createLocalEmbedder(cacheDir: string): Promise<EngramEmbedder> {
  if (cached?.dir === cacheDir) return cached.embedder
  await mkdir(cacheDir, { recursive: true, mode: 0o700 })
  try {
    const { pipeline, env } = await import('@huggingface/transformers')
    env.cacheDir = cacheDir
    const extractor = await pipeline('feature-extraction', 'Xenova/bge-small-zh-v1.5', { dtype: 'q8' })
    const embedder: EngramEmbedder = {
      model: 'Xenova/bge-small-zh-v1.5',
      async embed(texts) {
        if (texts.length === 0) return []
        const output = await extractor(texts as unknown as string[], { pooling: 'mean', normalize: true })
        const lists = output.tolist() as number[][]
        return lists.map(list => new Float32Array(list))
      },
      // The pipeline is held by the module-level cached, close only releases this instance's reference.
      close: async () => { if (cached?.embedder === embedder) cached = undefined },
    }
    cached = { dir: cacheDir, embedder }
    return embedder
  } catch (error) {
    throw new EngramError('EMBEDDER_DOWNLOAD_FAILED', 'Embedding model download/load failed; retrieval has degraded to pure keyword mode, check the network and retry', { cause: error })
  }
}
```

```ts
/**
 * Definitions and executors for the 5 engram_ tools. Tool schemas keep narrow parameters;
 * scope determines which database to read/write; when the embedding is missing, retrieval results are explicitly marked as degraded.
 * @module @kenz1117/dsh-engram/tools/create
 */

import type { ToolDefinition } from '@deepseek-ai/dsh-tools'
import { defineTool } from '@deepseek-ai/dsh-tools'
import type { EngramStore } from '../store/interface.ts'
import type { EngramEmbedder } from '../embedder/interface.ts'
import type { EngramScope } from '../types.ts'

/** Tool dependencies: lazily opened databases and an optional embedder. */
export interface ToolDeps {
  /** Resolve the target scope's database on each call (one each for user/project). */
  readonly openStore: (scope: EngramScope) => Promise<EngramStore>
  /** Optional embedder; undefined = degrade to pure keyword retrieval. */
  readonly embedder: EngramEmbedder | undefined
}

/** Converge scope from model parameters (missing falls back to project). */
function scopeOf(raw: unknown, fallback: EngramScope = 'project'): EngramScope {
  return raw === 'user' ? 'user' : raw === 'project' ? 'project' : fallback
}

/**
 * Build the 5 tool definitions (engram_save/search/timeline/update/forget).
 * @param deps - Database opener and embedder.
 * @returns The array of tool definitions that can be registered directly.
 */
export function createEngramTools(deps: ToolDeps): ToolDefinition[] {
  const save = defineTool({
    name: 'engram_save',
    description: 'Save a long-term memory (usable across sessions). kind: fact / preference / decision / episode / skill. scope: project is current project only, user is global.',
    parameters: {
      content: { type: 'string', required: true, description: 'Memory body, one complete sentence' },
      kind: { type: 'string', enum: ['fact', 'preference', 'decision', 'episode', 'skill'], required: true, description: 'Memory kind' },
      scope: { type: 'string', enum: ['user', 'project'], description: 'Scope, default project' },
      importance: { type: 'number', description: 'Importance 0-1, default 0.5' },
    },
    output: {
      schema: { type: 'object', additionalProperties: false, properties: {
        id: { type: 'string', required: true }, record: { type: 'object', required: true } } },
      render: (_args, value: { record: { id: string; kind: string; importance: number } }) => [{
        type: 'text',
        text: `Memory ${value.record.id} saved (kind=${value.record.kind}, importance=${value.record.importance}). Subsequent sessions can recall it with engram_search.`,
      }],
    },
    async execute(args: unknown, exec) {
      const input = args as { content: string; kind: 'fact' | 'preference' | 'decision' | 'episode' | 'skill'; scope?: unknown; importance?: number }
      const scope = scopeOf(input.scope)
      const store = await deps.openStore(scope)
      const record = await store.write({
        scope, kind: input.kind, content: input.content,
        importance: input.importance, sourceSessionId: exec.agent?.id ?? null,
      })
      return { id: record.id, record }
    },
  })

  const search = defineTool({
    name: 'engram_search',
    description: 'Semantic + keyword hybrid search of long-term memory. The user scope stores preferences and general facts; the project scope stores project conventions and decisions.',
    parameters: {
      query: { type: 'string', required: true, description: 'Search text' },
      scope: { type: 'string', enum: ['user', 'project', 'all'], description: 'Scope, default all' },
      limit: { type: 'number', description: 'Upper bound on the number of returned entries, default 8' },
    },
    output: {
      schema: { type: 'object', additionalProperties: false, properties: {
        degraded: { type: 'boolean', required: true }, text: { type: 'string', required: true } } },
      render: (_args, value: { degraded: boolean; text: string }) => [{ type: 'text', text: value.text }],
    },
    async execute(args: unknown) {
      const input = args as { query: string; scope?: unknown; limit?: number }
      const raw = scopeOf(input.scope, 'all' as never) === undefined ? [] : undefined
      void raw
      const scopes: EngramScope[] = input.scope === 'user' ? ['user'] : input.scope === 'project' ? ['project'] : ['user', 'project']
      const queryText = input.query.trim()
      const queryVector = deps.embedder === undefined || queryText === '' ? undefined : (await deps.embedder.embed([queryText]))[0]?.vector
      const results = await Promise.all(scopes.map(async (scope) => {
        const store = await deps.openStore(scope)
        return store.search({ text: queryText, scopes: [scope], limit: input.limit ?? 8 }, queryVector)
      }))
      const merged = results.flatMap(result => result.hits).sort((a, b) => b.score - a.score).slice(0, input.limit ?? 8)
      const degraded = results.some(result => result.degraded)
      const lines = merged.map((hit, index) =>
        `${index + 1}. [${hit.record.scope}/${hit.record.kind}] ${hit.record.content} (id=${hit.record.id})`)
      const text = degraded ? `(Semantic embedding unavailable, keyword search only)\n${lines.join('\n') || 'No hits'}` : lines.join('\n') || 'No hits'
      return { degraded, text }
    },
  })

  const timeline = defineTool({
    name: 'engram_timeline',
    description: 'Browse memories by time range and topic (descending order). No arguments defaults to the most recent 20.',
    parameters: {
      scope: { type: 'string', enum: ['user', 'project', 'all'], description: 'Scope, default all' },
      topic: { type: 'string', description: 'Topic substring' },
      since: { type: 'string', description: 'Start ISO time, e.g. 2026-08-01' },
      until: { type: 'string', description: 'End ISO time' },
    },
    output: {
      schema: { type: 'object', additionalProperties: false, properties: { text: { type: 'string', required: true } } },
      render: (_args, value: { text: string }) => [{ type: 'text', text: value.text }],
    },
    async execute(args: unknown) {
      const input = args as { scope?: unknown; topic?: string; since?: string; until?: string }
      const scopes: EngramScope[] = input.scope === 'user' ? ['user'] : input.scope === 'project' ? ['project'] : ['user', 'project']
      const sinceMs = input.since === undefined ? undefined : Date.parse(input.since)
      const untilMs = input.until === undefined ? undefined : Date.parse(input.until)
      if (input.since !== undefined && Number.isNaN(sinceMs)) throw new Error(`engram_timeline: since is not a valid time ${input.since}`)
      if (input.until !== undefined && Number.isNaN(untilMs)) throw new Error(`engram_timeline: until is not a valid time ${input.until}`)
      const rows = (await Promise.all(scopes.map(async (scope) => (await deps.openStore(scope)).timeline({
        scopes: [scope], topic: input.topic, since: sinceMs, until: untilMs, limit: 20,
      })))).flat().sort((a, b) => b.createdAt - a.createdAt).slice(0, 20)
      return { text: rows.map(record => `${new Date(record.createdAt).toISOString()} [${record.scope}/${record.kind}] ${record.content} (id=${record.id})`).join('\n') || 'Timeline is empty' }
    },
  })

  const update = defineTool({
    name: 'engram_update',
    description: 'Correct a memory: write a new entry and mark the old entry as superseded (the chain is retained, auditable).',
    parameters: {
      id: { type: 'string', required: true, description: 'Id of the old entry to correct (given in the engram_search result)' },
      content: { type: 'string', required: true, description: 'Corrected body' },
      scope: { type: 'string', enum: ['user', 'project'], description: 'Scope of the old entry' },
      kind: { type: 'string', enum: ['fact', 'preference', 'decision', 'episode', 'skill'], description: 'Kind, default inherits the old entry' },
    },
    output: {
      schema: { type: 'object', additionalProperties: false, properties: {
        record: { type: 'object', required: true }, superseded: { type: 'string', required: true } } },
      render: (_args, value: { record: { id: string }; superseded: string }) =>
        [{ type: 'text', text: `Corrected memory ${value.record.id} written; old entry ${value.superseded} archived and a supersedes chain established.` }],
    },
    async execute(args: unknown) {
      const input = args as { id: string; content: string; scope?: unknown; kind?: 'fact' | 'preference' | 'decision' | 'episode' | 'skill' }
      const scope = scopeOf(input.scope)
      const store = await deps.openStore(scope)
      const old = await store.get(input.id as never)
      if (old === undefined) throw new Error(`engram_update: entry ${input.id} does not exist`)
      const record = await store.update({
        id: input.id as never, scope, kind: input.kind ?? old.kind, content: input.content,
      }, undefined)
      return { record, superseded: input.id }
    },
  })

  const forget = defineTool({
    name: 'engram_forget',
    description: 'Forget a memory (soft delete, the user can restore it from the database).',
    parameters: {
      id: { type: 'string', required: true, description: 'Entry id' },
      scope: { type: 'string', enum: ['user', 'project'], description: 'Scope of the entry' },
    },
    output: {
      schema: { type: 'object', additionalProperties: false, properties: { id: { type: 'string', required: true } } },
      render: (_args, value: { id: string }) => [{ type: 'text', text: `Memory ${value.id} forgotten (soft delete, restorable).` }],
    },
    async execute(args: unknown) {
      const input = args as { id: string; scope?: unknown }
      const store = await deps.openStore(scopeOf(input.scope))
      const record = await store.forget(input.id as never)
      return { id: record.id }
    },
  })

  return [save, search, timeline, update, forget]
}
```

```ts
/**
 * dsh-engram: BharatCode Harness cross-session long-term memory plugin (host half).
 * Registers 5 engram_ tools and injects a user-level profile summary at session start.
 * @module @kenz1117/dsh-engram
 */

import { mkdir } from 'node:fs/promises'
import type { Context } from '@deepseek-ai/cordis'
import z from '@deepseek-ai/schemastery'
import { createUserMessage } from '@deepseek-ai/dsh-llm'
import type { Agent, PreStepDecision } from '@deepseek-ai/dsh-agent'
import { openEngramStore } from './store/sqlite.ts'
import type { EngramStore } from './store/interface.ts'
import { createLocalEmbedder } from './embedder/local.ts'
import type { EngramEmbedder } from './embedder/interface.ts'
import { resolveConfig } from './config.ts'
import type { EngramConfig, ResolvedEngramConfig } from './config.ts'
import { createEngramTools } from './tools/create.ts'
import type { EngramScope } from './types.ts'

/** Cordis plugin name (used by loader diagnostics and the injection source). */
export const name = 'dsh-engram'

/** Required services: the tool registry. */
export const inject = ['tools']

export { Config } from './config.ts'
export type { EngramConfig } from './config.ts'

/**
 * Plugin body: warm up the databases and embedder, register tools and profile injection.
 * @param ctx - Host context.
 * @param config - Optional config passed in by cordis.yml.
 */
export function apply(ctx: Context, config: EngramConfig = {}): void {
  const resolved: ResolvedEngramConfig = resolveConfig(config)
  void mkdir(resolved.dbDir, { recursive: true, mode: 0o700 })

  // Databases opened lazily: user always open; the project database is named by the process working directory (same project across sessions shared).
  const projectDbName = `project-${Buffer.from(process.cwd()).toString('hex').slice(0, 24)}.db`
  const stores = new Map<EngramScope, Promise<EngramStore>>()
  const openStore = (scope: EngramScope): Promise<EngramStore> => {
    const existing = stores.get(scope)
    if (existing !== undefined) return existing
    const path = scope === 'user' ? `${resolved.dbDir}/user.db` : `${resolved.dbDir}/${projectDbName}`
    const created = openEngramStore(path)
    stores.set(scope, created)
    return created
  }

  // The embedder is optional: a download failure does not block plugin loading, retrieval degrades automatically (fail loud on the first download error log).
  const embedderPromise: Promise<EngramEmbedder | undefined> = createLocalEmbedder(resolved.modelCacheDir)
    .catch((error: unknown) => {
      console.warn('[dsh-engram] Embedder unavailable, retrieval degraded to pure keyword mode:', error)
      return undefined
    })
  void embedderPromise

  ctx.tools.register(...createEngramTools({
    openStore,
    get embedder(): EngramEmbedder | undefined { return undefined },
  }))

  // Profile injection: on the first step of each round, append the user-level top-N memories as a dynamic context with a source.
  registerProfileInjection(ctx, openStore, resolved, embedderPromise)
}

/**
 * agent/pre-step waterfall: inject the profile when step===1. next() must be called to delegate the chain.
 */
function registerProfileInjection(
  ctx: Context,
  openStore: (scope: EngramScope) => Promise<EngramStore>,
  resolved: ResolvedEngramConfig,
  embedderPromise: Promise<unknown>,
): void {
  void embedderPromise
  if (!resolved.injectProfile) return
  ctx.on('agent/pre-step', async (
    { agent, step }: { agent: Agent; step: number },
    next,
  ): Promise<PreStepDecision> => {
    const decision = await next()
    if (step !== 1) return decision
    const store = await openStore('user')
    const top = await store.topActive('user', resolved.profileTopN)
    if (top.length === 0) return decision
    const text = [
      'User memory profile (dsh-engram, cross-session):',
      ...top.map(record => `- [${record.kind}] ${record.content}`),
      'Use engram_search to recall details; use engram_save to persist new facts.',
    ].join('\n')
    return {
      ...decision,
      messages: [
        ...decision.messages,
        createUserMessage({
          content: [{ type: 'text', text }],
          source: { kind: 'plugin', plugin: name, form: 'snapshot', sections: [{ name, text }] },
        }),
      ],
    }
  }, { prepend: true })
}
```

````markdown
# @kenz1117/dsh-engram

BharatCode Harness's cross-session long-term memory plugin: the Agent remembers user preferences, project conventions, and experience facts across sessions and projects.

## Using This Package

```sh
dsh plugin --profile web add @kenz1117/dsh-engram
```

cordis.yml can be used without configuration (default `~/.dsh/engram` databases, profile injection enabled). Optional configuration:

```yaml
- id: dsh-engram
  name: '@kenz1117/dsh-engram'
  config:
    dbDir: '~/.dsh/engram'      # Root directory for databases and model cache
    injectProfile: true          # Inject a user profile summary at session start
    profileTopN: 8               # Upper bound on the number of injected entries
```

Tools: `engram_save` / `engram_search` / `engram_timeline` / `engram_update` / `engram_forget`.

## Understanding the Implementation

- Two-layer database split: `user.db` is globally shared; `project-<cwd>.db` is isolated by working directory.
- Hybrid retrieval: FTS5 (trigram, Chinese-friendly) + local vector (`Xenova/bge-small-zh-v1.5`, 512-dim, quantized weights) RRF fusion + one-hop relationship edge expansion.
- Corrections go through the supersedes chain: `engram_update` archives the old entry and creates a `supersedes` edge, the chain is complete and auditable; the operation log table records all writes/modifications/forgets.
- The embedding model requires a network connection to download on first use (about 50MB), afterwards fully offline; on download failure, retrieval automatically degrades to pure keyword and marks it in the result.

## Model Experience

### Request context and condition

#### What the model sees

Each round's first step of a session appends a plugin-sourced user snapshot: `User memory profile (dsh-engram, cross-session):` plus the user-level memory list (default at most 8 entries). Tool call results are a plain-text line list (including id, scope/kind annotation and degradation note).

#### Token effect

Profile injection is a conditional fixed cost (count × content length); tool schemas are a resident cost (5 narrow-parameter tools).

#### KV Cache effect

The profile text changes with the memory database content — changes only happen at round boundaries after the first round of a session; when the injected entries are unchanged within the same session, the prefix stays stable; the tool schemas are constant and do not affect the prefix.

## Known Limitations and Deferred Work

- **Auto-ingest not implemented** — at session end, no candidate memories are extracted from the log, relying on the model's explicit call to `engram_save`; phase 2 adds an ingest hook on the session event stream (`ingest: off | light | eager`).
- **Flywheel not implemented** — contradiction detection, distillation, decay scheduling and the four audit tools `engram_review/stats/export/distill` are in phase 2.
- **The source attribution chain only has sessionId** — round and event seq attribution will be completed with auto-ingest.
````
