# dsh-engram v0.7.1 Implementation Plan (UI Polish + Fixes + Publishing Preparation)

On top of v0.7.0's "admin panel zustand → hooks / dual-database health score / corridor bird's-eye / tour proposal / refurbishment checklist", this release only does closing: UI layout polish, typecheck cleanup, privacy metadata interaction, and supplement the copy and version for publishing to the "AGI Architecture Exploration" category of dsh-market.

## Key Design Decisions (Locked In Before Implementation)

1. **The "Steward's Daily" as a whole bar serving as a global view for scope switching** — always present above the tabs, left/right two zones of equal height (scale 2×2 + last 7 days 5 cells), scope follows the Header's three-grid single switcher. Remove the duplicate scope chip + `ScopeChipRow` component + dead `scopeLabel` dictionary key that was in the original daily bar title row; the Header and `observeScope` local state are all merged into the global `scope`. Done in two steps: first free it from the top of the health score card (at the start of v0.7.1), then do the grouped grid.
2. **Information category clustering (mainCol = global + action type; sideCol = retrospective type)** — the refurbishment card (rectification suggestion) moves from the right column to the main column, inserted after the search desk; the right column is left with tour proposal + steward's log. This way the corridor bird's-eye + refurbishment share the "what to do to the palace" narrative, and the right column is purely "what has happened / what is about to happen".
3. **Full unification of design tokens** — `--fs-tag: 10px` newly added; the list / skeleton / pill / segItem / viaChip / actScope / empty-state magic numbers (6px, 10px, 12px, 13px etc.) are all replaced with `--space-*` / `--radius-*` / `--fs-*`. Delete the unreferenced `.kpi` / `.teleItem` / `.scopeChip` style blocks.
4. **Privacy metadata changed from footnote to exclamation badge** — exclamation mark on the right of the steward's daily card title row + 11px short label "data only aggregated locally · not sent out", hover / focus pops up a 260-320px long description (covering the op_log persistence semantics + cleared on restart). This way say goodbye to "last 7 days locally aggregated · not sent out" occupying a whole line + the divider line above it.
5. **Steward's log limited height 280px + internal scroll + bottom 16px fade mask** — 20 full entries about 700px+ stretches the whole observation column, the height limit coordinates with the corridor bird's-eye; padding-bottom compensates the mask band height, when scrolled to the bottom the last entry is fully visible, the vertical line (`.timeline::before`) scrolling with the content is expected behavior.
6. **Narrow screen anti-squeeze / two columns fall back to one** — header adds `flex-wrap` + `row-gap`; `.layout` / `.observeTop` / `.teleBar` fall back to one column at ≤960px, sidebar cancels sticky and flows in order.
7. **Fix typecheck / cordis API migration** — 18 existing errors cleaned up: ① `backup/tar-stream.ts` missing `Writable` import; ② `backup/tar.ts` unused variable + readonly push dead code; ③ `CorridorMap.tsx`'s `EdgeStyle.dash` errors under `exactOptionalPropertyTypes`; ④ `EngramPanel.tsx`'s `MemoryRow.scope` / `StatsPart.scope` / `ReviewBody` / `scope` persisted state all relaxed to tri-state (shared scope was already three-grid in the UI, the type layer was missed); ⑤ cordis removed `session.events`, six call sites uniformly switched to `snapshotEvents()`, and the previously unimported `writeMirror` ReferenceError was fixed; ⑥ `tests/{consolidation,mirror,rationale}.spec.ts` three places missing fields (sourceSeq, outcome conditional expansion, delete extra status).
8. **dsh-market publishing** — `dsh-market`'s data source is the community-maintained awesome-dsh-plugin list, category is self-selected by the author with no review. This repo's target category: **AGI Architecture Exploration** (dsh-engram reconstructs agent long-term memory as a cognitive science methodology under the memory palace metaphor, fitting the category's "agent architecture exploration" narrative). README adds AGI Architecture Exploration summary and keywords.
