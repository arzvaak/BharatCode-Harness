# Bundled OCR language data

`tessdata/eng.traineddata.gz` is the English `4.0.0_best_int` model published in `@tesseract.js-data/eng@1.0.0`. Tesseract.js documents this integerized `tessdata_best` model as its default for the LSTM-only OCR engine.

The model is distributed under Apache-2.0. See [LICENSE](LICENSE) and [manifest.json](manifest.json) for its provenance, package integrity, byte size, and SHA-256 digest.
