# Agent Note: 独立聊天文件夹

Status: implemented

[English](2026-10-10-independent-chat-folders.md) | 中文

## 问题

启动流程登记默认工作区，通用新建会话继承当前或最近的工作区。独立的空白会话无法输入，因此普通聊天也需要项目归属。

## 决策

通用新建会话在 `$DSH_HOME/chats` 下创建不登记为工作区的独立聊天文件夹。只有显式工作区创建才附加归属。启动恢复已保存的选择，或在历史为空时创建独立空白聊天。现有日志和归属保持不变。侧边栏的“全部聊天”和“工作区”视图共享同一份历史。

## Consequences

独立聊天使用各自的工作目录，不会增加工作区条目。需要项目目录的调用方必须明确提供工作区或 cwd。已有聊天日志保留原有路径。

## 验证

Host 创建测试证明独立文件夹和显式 cwd 处理。客户端测试覆盖选择、后续导航替代和独立输入框就绪。真实 Host 浏览器场景覆盖空启动、显式工作区归属、通用新建会话和重新加载。Linux AppImage 冒烟测试检查打包后的首次使用行为。

## 考虑过的替代方案

继承当前工作区会让普通聊天依赖之前的导航。共用一个工作目录会混合不同聊天的文件。把生成的文件夹登记为工作区会使项目列表杂乱。这些方案无法同时提供独立聊天存储和显式项目归属。
